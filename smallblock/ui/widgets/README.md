# SmallBlock UI Widgets

This package contains the built-in widget library used by SmallBlock.

## Current Widgets

- Widget
- Panel
- Window
- Label
- Button
- TextBox
- Toolbar
- StatusBar

## Widget Hierarchy

Widget
├── Panel
│   ├── Window
│   ├── Toolbar
│   └── StatusBar
├── Label
├── Button
└── TextBox

## Design Principles

- Lightweight
- Pure Python
- Renderer independent
- Hierarchical parent/child system
- Suitable for games, editors, and tools
- Extensible through inheritance
