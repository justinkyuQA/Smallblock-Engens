# SmallBlock UI

The SmallBlock UI package provides a lightweight widget toolkit for
building editors, tools, games, and debugging interfaces.

## Components

- Window
- Panel
- Label
- Button
- TextBox
- Toolbar
- StatusBar

## Supporting Modules

- UIManager
- UIFactory
- Layout
- Theme
- Style
- UIRegistry

## Goals

- Lightweight
- Pure Python
- Extensible
- Runtime-friendly
- Engine-independent

Future widgets include:

- Checkbox
- RadioButton
- Slider
- ProgressBar
- Image
- ListView
- TreeView
- Menu
- TabView
- DockPanel
